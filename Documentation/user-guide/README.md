# Magellon user guide

Generate the PDF:

```bash
cd Documentation/user-guide
./guide.sh pdf
```

This writes `Magellon-User-Guide.pdf` in this folder. It needs only Docker.

To change the guide, edit `guide.md` (the text) or the pictures in `images/`,
then run the command again.

To retake the screenshots, see the notes at the top of each script in `shoot/`.
